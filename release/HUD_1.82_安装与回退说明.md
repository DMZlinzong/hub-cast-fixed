## 新增功能（本版）

1. **「开始/停止记录」按钮**：控制诊断日志记录；缓冲保留最近 **10 分钟 / 上限 6000 行**，纯内存，不需要存储权限
2. **「手机扫码下载日志」按钮**：
   - 内存日志 → UTF-8 TXT（含毫秒时间戳、action、KEY_TYPE、extras 键名+数据类型、红绿灯字段值、原始 JSON 红绿灯片段、解析成功/失败及原因）
   - 应用内临时 HTTP 服务（随机端口 + 随机 18 位十六进制下载令牌）
   - 二维码 + 备用文字 URL（长按可复制）显示在车机屏幕
   - **下载一次成功或 5 分钟无人下载 → 服务自动关闭**；只提供本次日志一个路径，无目录列表/上传/远程执行
   - 全程局域网直连，**不经任何第三方云服务器**
3. **日志增强**：extras 键值带数据类型标注；字符串 extras 中含 traffic/light/countdown/灯 的原始 JSON 片段自动截取（经纬度数字脱敏）；解析层显式标注「成功/部分成功/失败及原因」
4. **隐私脱敏**（下载前生效）：GPS/坐标/位置/账号/IMEI/设备标识类键只记键名；JSON 中 lat/lon/lng/latitude/longitude 数值一律打码

## 安装

1. 下载 `HUD_1.82_CruiseDebug_QR.apk` 到车机，覆盖安装（无需卸载旧版）
2. 确认版本行显示 **1.82**

## 使用（车辆安全停放时）

1. 高德开自由巡航，让高德界面显示倒计时约 1 分钟（期间保持「开始记录」状态，默认已开）
2. 打开 HUD 投屏 App → 点「手机扫码下载日志」
3. **手机连接与车机相同的 Wi-Fi / 热点**（同一网段）→ 手机扫码 → 浏览器直接下载 TXT
4. 扫码打不开时：长按车机屏幕上的 URL 复制到手机浏览器重试；仍失败 → 大概率是热点「客户端隔离」或不同网段，改为手机开热点、车机连手机热点后再试
5. 把下载的 txt 发回

## 已知限制（如实标注，非缺陷掩盖）

- **二维码只在同一局域网内可用**：车机 Wi-Fi 若开了客户端隔离（AP 隔离），扫码必然失败，界面有明确提示，请改用「手机开热点 → 车机连接」
- 车机未连任何 Wi-Fi/热点时，点下载会直接提示「未连接局域网」，二维码不生成
- HTTP 为明文传输（局域网内短时服务，仅含脱敏诊断数据，风险可控）；manifest 已声明 `usesCleartextTraffic=true` 确保不被 Android 9 明文策略拦截
- 诊断版 HTTP 服务经过 JVM 端到端冒烟测试（下载/404/自动关闭/二维码），实车网络环境为**待车机验证**

## 回退

- 任意旧版（1.79 / 1.80 / 1.81）**直接覆盖安装即可回退**，签名相同、数据互通，无需卸载
- 如需彻底清除：设置 → 应用 → HUD投屏 → 卸载（诊断日志存在 App 私有目录，卸载即清除，不会残留存储卡）
